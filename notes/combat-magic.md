# Jurassic War — бой, магия, предметы (реверс pwar.exe)

Источники: `out/decomp_named.c` (адреса функций указаны как FUN_xxxxx), `pwar.img` (база 0x10000). Запись юнита — смещения от базы 0xe4400 (U_*).

| +0x0c / +0x0e | HP max / HP cur | |

| +0x11 | **мана текущая** — раньше названо «MP_MAX» | тратится при касте (FUN_0001c092) |
| +0x0f / +0x10 / +0x12 | ATK / DEF / SPD | |
| +0x13 u16 | **FOOD — еда, которую несёт юнит** (не «цена») | старт = T_STATS[6..7]: люди 30, звери 150…1000; ею платят в арсенале |

## 1. Формула урона
Функция атаки **FUN_0001e758** (ESI = атакующий, EDI = цель). Вызывается из FUN_0001a7cb (люди — каждый 8-й кадр анимации атаки, звери — на 6-м кадре из 8).

1. Обоим +1 XP (+0x27).
2. Здания (типы 24–39) и тип 0 не атакуют.
3. Базовый урон **FUN_0001ea75**:
   ```
   d = max(ATK_a − DEF_t, 0)
   dmg = (d >> 4) + (ATK_a >> 5) + 1
   ```
   т.е. минимум 1, без случайности.
4. Бонус оружия по типу цели: если экипировано оружие (слот +0x15) с id `w` — `dmg += TBL_W[w][тип цели]`, где `TBL_W[w] = *(0x37af4 + w*4)` (блоки по 0x47 байт от 0x37b54: 40 байт по типу цели + 31 байт по id предмета). Без оружия используется блок 0x37b54 (w=0).
5. Щит цели: если у цели экипирован щит id `s` — `dmg −= TBL_W[w][40 + s]`; если стало 0 или ушло в минус → `dmg = 1`.
6. Дальше — по id оружия атакующего через jump-table @0x1e9a8:
   - id **4, 5, 6, 7 — метательное оружие** (луки/копья): выстрел снарядом. Перед выстрелом проверка «пробития щита»: `if (dmg + A[k][тип цели] < B[k][id щита цели]) → выстрел не производится` (блокирован щитом). Таблицы A/B: id4 → 0x37990/0x379b8, id5 → 0x379d7/0x379ff, id6 → 0x37a1e/0x37a46, id7 → 0x37a65/0x37a8d. Ненулевые пороги только у щитов id 9, 10, 21 (Moon Shield), 24 (Sun Shield): 2/7–10. Снаряд создаётся FUN_0001c2a4 (взять из пула) + FUN_0001b730; урон кладётся в поле снаряда +0x07.
   - все остальные (0–3, 8+, без оружия) — **ближний бой**, урон применяется сразу (метка 0x1ead3 / FUN_0001eada).
7. Применение урона (FUN_0001eada / 0x1ead3): `HP −= dmg`. Для зданий (тип ≥ 26): при падении ниже половины HP — звук FUN_0001ffda и ещё −2. Если HP ≤ 0 → смерть (0x1ebdc). При попадании по своему зданию игрока — сообщение «My structure is attacked»; по зданию ИИ — ИИ собирает защитников (см. notes ИИ).

**Случайности в бою нет.** ГСЧ игры — **FUN_00020469**: `r = (seed + тик) % range; seed += (seed+тик)/range; seed ^= tbl[q>>28]` (DAT_00031b58 = range, DAT_00031b5c = seed, DAT_00031ab4 = счётчик тиков). Используется для спавна редких предметов, стартового направления и т.п., но не для урона/попаданий.

### Дальность
**FUN_0001a051** — цель «в досягаемости», если её прямоугольник пересекается с прямоугольником юнита, расширенным на R:
- ближний бой: R = 0 (нужно касание);
- люди 1–4 с оружием id 4: `R = DAT_0003055e[SPD>>6]`; с id 5–7: `R = DAT_0003055e[SPD>>5]`; маги 5–8: `R = DAT_0003055e[SPD>>5]`; тип 13 (purple dragon): R = 64.
- таблица DAT_0003055e = [64,64,96,96,128,128,160,160,192,192,224,224,256,…] пикселей (тайл 32px) — **дальность стрельбы растёт со SPD**.

### Снаряды
Пул записей по базе 0xf2500 (списки DAT_00031b74 активные / DAT_00031b78 свободные, FUN_0001c2a4 alloc, FUN_0001c2ef free). Поля: +04 спрайт (+ направление), +05 время жизни `= (DAT_0003055e[SPD>>5] + 40) / 2`, +06 ведущая ось, +07 урон (0 = не бьёт), +08 источник, +0c цель, +10/+12 позиция, +14..+1a ошибки Брезенхема, +1c/+1e шаг (DAT_00030504[dir]*2). Движение **FUN_0001b149**: 4 подшага за тик; при попадании в bbox цели (T_SPR_W/H) → FUN_0001eada (урон), время жизни = 2. Если время истекло — снаряд исчезает (промах, цель ушла). Обход всех снарядов — FUN_0001ab4c (jump-table обработчиков по типу +04; отрицательные типы — эффекты заклинаний).

## 2. Смерть, опыт, уровни
- Смерть (0x1ebdc): HP=0, state=0x6f ('o', труп). Если жертва — здание, на этом всё. Иначе убийца получает XP **FUN_0001ea92(жертва)** = `((HPmax+MAG+ATK+DEF+SPD)² / 4) + XP жертвы`, ставит FLAGS50=0xd (анимация победы) и **прокачивается**:
  - тип < 14 (люди и динозавры 9–13): FUN_0001ec47 (полный левел-ап) и затем **смена класса FUN_0001f6fe**: тип 1 (пещерный человек) с HPmax > 69 → тип 2 (воин), с ATK > 69 → тип 3 (охотник/берсерк);
  - типы 14–23 (звери): FUN_0001f20f (растут HP/ATK/DEF/SPD пропорционально);
  - типы 24+: FUN_0001f426 (только HP).
- Стоимость +1 к стату: **FUN_0001f6f3(stat) = stat²/2 + 10 XP**. Растут только статы из маски +0x0b, и только пока стат < потолка. Потолки — по игроку и типу: `PTR_DAT_00030dd8[player] + T_TYPE_STATOFF[type]` (u16 HP,MAG,ATK,DEF,SPD). Дефолт (0x31c68): тип1 70/0/70/100/100; тип4 100; типы 2,3,5–13 — 254 (маги MAG 200, тип 8 — 254); звери ниже (raptor 220/220/200/120, wolf 50/40/45/80). Прирост распределяется пропорционально `cap_i / Σcap`.
- Анимация смерти FUN_0001a8dc: кадры `T_DEATH_A[type] + DAT_00036f70[dir] + (счётчик>>5)`, затем `T_DEATH_B[type] + …` (таблица пар @0x36f10).
- **Лут с трупа** (0x193a7..0x193d8): все предметы инвентаря выкладываются на карту объектами; еда (id 0x1e) — в количестве **FOOD/2** (если FOOD>1). Звери со старта несут еду (слот 6 = 0x1e, FOOD = T_STATS[6..7]): raptor 1000 → 500 мяса и т.д. Это и есть «охота».
- Объекты на карте: список от DAT_00031b7c, поля +0x34 тип, +0x35/+0x36 клетка, +0x38 таймер (25), +0x3a количество; в сетке BI бит 1 = «на клетке лежит объект». Создание FUN_0001c5a8(type, x, y, amount) / FUN_0001cdf3, удаление FUN_0001ca9f. Подбор (FUN_0001c5xx около строки 7440): по флагам предмета — оружие в слоты 0–2, щиты 3–5, редкие (флаг 0x10) в 9–10, прочее в 6–8; еда добавляется к FOOD (FUN_0001c679).

- **Покупка** FUN_0001763c(id): если флаг 8 и `цена ≤ FOOD` юнита → предмет в слот, FUN_0001c6e9 списывает еду. Платит сам юнит тем, что несёт.
- **Продажа/дроп** FUN_000175e8(слот): снимает экипировку; если предмет с флагом 8 — FUN_0001c679 добавляет еду (половина цены задаётся вызывающим кодом), слот очищается.
- **Автовыбор щита** FUN_0001c8ec: предпочитает щит с флагами 0x15 (id 21/24), иначе слот, указанный в +0x0a, иначе первый непустой; **щит нельзя держать с двуручным оружием id 5–7**.
- **Автолечение зельями** FUN_0001c72b: после атаки, если HP < половины, съедает первое зелье id 11–14 из слотов 6–8.
- **Еда как лечение** FUN_0001c6e9(1) внутри регенерации (FUN_00018ab2): люди/динозавры (тип < 14) каждые 4 HP «съедают» 1 еду из FOOD вместо естественной регенерации; когда FOOD=0 слот еды очищается.
- **Редкие предметы появляются случайно** (около строки 2350): раз в 32 тика с шансом 51/10000 в случайной клетке карты создаётся объект типа 0x0f..0x1d (id 15–29) и выводится «--- Appear the <имя> ---» (строки @0x35444, индекс = тип−0xf).

## 4. Магия
Заклинание открывается, когда **MAG (+0x0d) ≥ порог**; при этом в +0x17 ставится бит (FUN_0001f475, вызывается при росте статов). Доступность по типу юнита задаётся масками игрока `PTR_DAT_00030e64[player]` (дефолт @0x32760): типы 1–4 — 0x3f (только базовые приказы), тип 5 — биты 8–12, тип 6 — биты 14–17, тип 7 — биты 19–22, тип 8 — биты 24–26. Т.е. **4 магических класса (типы 5–8) по 5/4/4/3 заклинаний = 16**.

Таблица заклинаний **@0x30b60, 4 байта на запись** `[порог MAG, стоимость маны, сила, 0]`; индекс = id − 0x80; стоимость списывает FUN_0001c092 из +0x11. Эффекты — **FUN_0001b917(id)** (jump-table). Все касты дают XP кастеру.

## 5. Читы (попутно)
Строки ~16660–16710: меню/коды: case 1/2 — открыть/закрыть всю карту (бит 0 сетки BI = «разведано»), case с 0xfe — всем выделенным своим юнитам (+0x07 & 0x80) статы 0xfe. Не в теме, отмечено для других.
