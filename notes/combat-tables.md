# Боевые таблицы: оружие × тип цели, оружие × щит

Дамп из `pwar.img`. Машинная копия (все 24 блока целиком) — `reimpl/data/weapon_tables.json`.

## Формула урона (`0x1e934`, после `0x1ea75`)

```
d    = max(ATK_атакующего − DEF_цели, 0)
dmg  = (d >> 4) + (ATK_атакующего >> 5) + 1          # случайности нет вообще
blk  = WEAPON_BLOCK[id оружия]                        # 0x37af4[id]; без оружия — блок 0x37b54
dmg += blk[тип цели]                                  # таблица 1
dmg -= blk[0x28 + id щита цели]                       # таблица 2; если dmg ≤ 0 → dmg = 1
```

Блоки лежат подряд по 0x47 (71) байта: `0x37b54 + 71·id`, id 0..23. Первые 40 байт блока —
бонус по типу цели, следующие 31 — вычет по id щита цели.

## Замечания для реимплементации

- Щитов в игре пять: 8 Wood-Shield, 9 Iron-Shield, 10 Wather-Shield (опечатка оригинала),
  21 Moon Shield, 24 Sun Shield. Прочие id в этой половине блока нулевые.
- Бонус оружия прибавляется ДО вычета щита; итог никогда не меньше 1.
- Moon/Sun Shield срезают 15/20 почти против всего, поэтому базовое оружие против них
  всегда бьёт на 1. Пробои видны в таблице: Fire-Arrow против Moon Shield срезается на 20
  (то есть хуже), Sun Shield против Moonlight Sword — только 10, против Ax of Darkness — 17.
- Wather-Shield почти бесполезен (2–4), но против Fire-Arrow даёт 12.
- По зданиям (типы 26–39) сильнее всего Hammer of Darkness (+20), Ax of Darkness (+10),
  Stone-Ax (+4..+8) и Fire-Arrow (+6) — снос базы делается конкретным оружием, а не «числом дамага».
- Против зверей (14–19) резко выделяются Volcano Spear (+20) и Spear (+5..+7);
  против людей — Celestial Sword (+18..+20) и Moonlight Sword.
- Метательное оружие (id 4–7) **никакой дополнительной проверки щита не проходит** — jump-table
  `0x1e9a8` сразу создаёт снаряд. Пары таблиц `0x37990/0x379b8` и далее, которые раньше считались
  «пробитием щита», на самом деле относятся к атаке магических классов 5–8 (GAME-LOGIC §5.1,
  `notes/combat-spec.md`), и вычет щита в них к тому же мёртв: движок индексирует таблицу номером
  слота (3–5, там нули) вместо id предмета.
