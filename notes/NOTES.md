# Jurassic War (TRIC, 1997) — заметки по реверсу

Папка: ../PWAR (распакован Jurassic_War.rar с old-games.su)

## Исполняемый файл
- pwar.exe — 32-бит DOS, Watcom C/C++ 1994, формат LE, экстендер DOS/4GW. Версия "TRIC(R) Jurassic war V1.05E".
- Требует CD (CDEMU2.COM эмулирует диск d:). Ошибочные строки: VESA, mouse, sound, CD-ROM.
- Сохранения: _PWARSAV.000, конфиг C:\PWAR.DAT / _SETUP.DAT.

## Контейнеры _PWARxx.TR? (скрипт trc_list.py)
Заголовок 0x20 байт: magic "TRC\x1a"/"TRS\x1a"/"TRW\x1a", u32 n1 (ёмкость таблицы), u32 n2 (записей), u32 tabSize; данные с 0x20+tabSize.
- TRC: записи 32 байта: name[12], u32 off, u32 size, u32 size2, u32 0. size!=size2 → сжато (алгоритм пока не установлен).
- TRS (спрайты): записи 16 байт: u32 off, u16 w, u16 h, i16 x4 (hotspot/offsets). Без имён, без палитры в файле.
- TRW (звук): записи 16 байт: u32 off, u32 size, u16 ch?, u16 rate (11025/22050), u16 bits(8), u16 ...

## Обновление (2026-09-07, ночь) — ВСКРЫТО
- ВАЖНО: поле `tab` в заголовке = смещение начала данных от начала файла (уже включает 0x20), т.е. `base = tab`, НЕ `0x20+tab`.
- Запись TRC (32 байта): name[12], u32 off, u32 unpackedSize, u32 storedSize, u16 checksum16 (сумма байт распакованных данных), u8 packed(1=LZSS), u8 pad.
- Сжатие = LZSS (pwar.exe @0x2b40e, бит-ридер @0x2b3c4): биты MSB-first; флаг 0 → литерал 8 бит; флаг 1 → длина 5 бит + АБСОЛЮТНАЯ позиция 12 бит в кольце 4096 (кольцо изначально нули, позиция записи растёт с 0). После копирования, если длина < 31, скопированные байты дописываются в кольцо; при длине 31 — нет. Реализация: `tools/lzss.py`. Все 1354 записи TRC распакованы, контрольные суммы сошлись (`tools/extract_all.py` → `out/extract/`).
- Эмулятор реального кода (unicorn): `tools/emu_lzss.py` — эталон.
- Ghidra 12 headless: образ `pwar.img` (LE распакован `tools/le_dump.py`, релокации применены), проект `ghidra_proj`, декомпилят `out/decomp.c` (608 функций), список `out/functions.txt`.
- Графика: .SCR = 640x480x8 raw, .PAL = 768 байт 8-бит RGB; MAIN.PAL — игровая палитра (подходит к спрайтам и тайлам). TRS-спрайты = raw w*h 8 бит, цвет 0 прозрачный. Тайлсеты TILEn.TRT = 591 тайла 32x32 raw.
- Карта (9 секций): SI = ASCII "48*48-tile0-grp1-st1" (размер, тайлсет, группа, ...). BG = u16[176][256] (буфер фикс. 256 в ширину; реально W*H): бит 0..10 индекс тайла, биты 11..13 флаги (1..7). OB 57600 / OI 8000 / OM 10800 / BI,MO 256x176 байт / EV 160 / GI 7072 — ещё не разобраны (объекты, юниты старта, события).
- Драйверы MODxx.COM — "MOD player for SB 1.x,2.00" — модули плеера музыки.
- Рендеры: `out/img/` (MAIN.png, map000/001/040.png, tileset0.png, sheet04_units_a.png).

## Анимации юнитов (пак 04, TRS) — из таблиц pwar.exe
- Таблица баз стойки @0x36dd8 (u16): люди 0,65,130,…,455 (8 шт. по 65 кадров), звери 1685,1725,…,2245 (15 блоков по 40; блоки 1925 и 2045 пустые).
- Базы ходьбы @0x36e32 = стойка+5; базы атаки @0x36e8e: люди стойка+45, звери стойка+25.
- Направления: 8 игровых → 5 спрайтовых через карту @0x36e06 [0,1,2,3,4,3,2,1]; направления 5..7 рисуются зеркально по горизонтали. Спрайтовые: 0=вниз, 1=вниз-вправо, 2=вправо, 3=вверх-вправо, 4=вверх.
- Смещения по направлению: люди ходьба @0x36e6c [0,8,16,24,32,…] (8 кадров), атака @0x36e78 [0,4,8,12,16,…] (4 кадра); звери ходьба @0x36ec2 [0,4,8,12,16,…] (4 кадра), атака @0x36ed2 [0,3,6,9,12,…] (3 кадра).
- Итого блок человека: 0–4 стойка (5 напр.), 5–44 ходьба, 45–64 атака. Блок зверя: 0–4 стойка, 5–24 ходьба, 25–39 атака.
- Дальше в паке: 520–1624 снаряды/оружие, 1625–1684 отдельный блок (человек, 61 кадр), 2285–2431 смерти/взрывы (таблица смертей @0x36f10 парами), 2432–2530 здания, 2531–2570 иконки предметов, 2571–2600 иконки построек, 2601–2628 портреты, дальше эффекты и растительность (2808–2816 деревья/пальмы).

## Структура юнита в памяти (из декомпилята)
Записи юнитов — связный список от DAT_00031b6c, поля по смещению от базы 0xe4400: +04 тип (byte, 1-based; таблицы по типу: 0x303b6/0x303b8 размер w/h ×4, 0x36d82 таймер, 0x33358), +06 владелец, +2f/+31 x,y в пикселях (int16; &0x1f — позиция внутри тайла 32px), +3d направление, +4f счётчик анимации, +5b флаги (bit0 = мёртв), +60 next. Сетка карты в памяти: 0x10ce74 (256 байт на строку, = BI) и 0x117e74 (= MO); в коде читаются как битовые поля (&2, >>2, >>4).
Ширина/высота карты: DAT_00031af8 / DAT_00031afc.

## Секции карты (уточнение)
- OB/OI/OM одинаковы у карт с одним тайлсетом → это данные тайлсета (объекты/проходимость), не карты.
- BI: сетка 256×176 байт, значения = (вид<<2)|флаги: (v&3) 0/1, (v>>2) 0..9 — объекты/препятствия карты. MO: редкие точки — 1..8 (вероятно стартовые позиции/игроки), 48, 80+, 128+ (события/монстры).
- GI (7072 байт): заголовок: +0x0c u16 (0/256/512/1280/2048/2816 — растёт с размером карты, вероятно старт камеры), +0x14 = 50 (стартовая еда?), +0x18 u16 «7936+n», далее блоки u32 с пиксельными координатами (W*32, H*32 на +0x44/+0x48, старт игрока на +0x1c/+0x20 и т.п.). Остальное — по 8 игроков × ~ 800 байт (плотно заполнено с 0x180 до 0x1b80).
- Названия сценариев в SI: "48*48-tile0-grp1-st1", у обучалок "501_0_t", у демо "demo #2", у пака 13 "m064064_0".

## Характеристики юнитов (pwar.exe @0x37654, запись 10 байт на тип, индекс = тип*10)
Поля (по коду инициализации юнита @FUN около строки 7930 decomp.c): [0]=HP (→+0c max,+0e cur), [1]=MP cur (+0d), [2]=MP max (+11), [3]=атака (+0f), [4]=защита (+10), [5]=скорость (+12), [6..7]=цена в еде u16 (+13). Предмет в руках +16 (0xff нет); бонусы предметов: атака @0x379ff, защита @0x37a46 (15 предметов: Celestial Sword… Skull Stick).
Типы 1-based: 1–8 люди (по одному на племя, в порядке паков спрайтов), 9–23 звери, 24–25 «строители/носильщики» (без ходьбы, спрайты людей), 26–39 здания (96×64 / 64×64, HP 160–255).
