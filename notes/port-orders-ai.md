# Порт, тема E: очередь приказов, ИИ, конец шага, победа

Файл: `reimpl/js/port/orders_ai.js`. Кейсы: `reimpl/cases/e_*` (63 кейса, все проходят `node js/test/fntest.mjs cases/e_*`).
Интеграция: `compare.mjs traces/m0_t0` — 200/200 шагов, `traces/m2_t0` (ИИ активен, слот 1) — 300/300 шагов.

## Портировано (адреса оригинала)
- Очередь приказов: 0x13f4c (сброс/раздача/применение), 0x1419e (раздача ожидающего UI-приказа по таблицам 0x141f8/0x14218), 0x14854 (снять ожидающий приказ), 0x14895 (добавить запись; сетевая контрольная сумма портирована, отправка в COM — нет).
- Обработчики UI-приказов: 0x14398 (идти с построением; помощники 0x1477e/0x147e7), 0x145cd (атака), 0x14621, 0x14642, 0x14673, 0x1468d, 0x1469a/0x146c5/0x146fa (заклинания; проверка доступности 0x14873 — чужая, вызывается через реестр).
- Прямой приказ 0x19f43 («идти в точку»). Сетки: 0x1a3db (занять тайл владельцем), 0x1a42c (освободить).
- Конец шага: 0x200fe (очередь звуков — только обнуление заявок), 0x1ab4c (обход снарядов, диспетчер по таблицам 0x1ab84/0x1ac98; сами обработчики — тема B), 0x1c340 (бит предмета в BI), 0x1c370 (гниение трупов/исчезновение предметов; освобождение записи 0x1ca9f — чужое).
- ИИ: 0x15634 (диспетчер по состоянию слота, таблицы 0x156b4/0x156d0), состояния 0x156ed/0x1572f/0x157ab/0x157b7/0x157c6/0x157d6/0x157e1, установка состояния 0x157e9/0x157f1/0x157fb, автоматы задач 0x1580e/0x15885/0x158fb/0x15982, помощники 0x15a0a/0x15a3e/0x15ac6/0x15b20/0x15c07/0x15ca1/0x15d79/0x15e45/0x15e82/0x15f1c, инициализация 0x15da1, смена цели 0x17d94/0x17db1/0x17dd4.
- Победа/поражение (только симуляция, без экранов): 0x17728, 0x17861 (диспетчер по таблице 0x36a60), 0x17d5f, счётчики 0x17879/0x178e7/0x17947, все 26 обработчиков целей миссий (0x17989…0x17d5c).

## Не портировано / чужое
- Сеть: 0x14942, 0x148fe, 0x282d9 — при `[31b69]!=0` порт бросает исключение.
- 0x1ced8/0x1cfcb/0x1d12e (заказ по таймеру типа, респавн зверей/растений) — захвачены другой темой до меня.
- Экраны победы/поражения (хвост 0x17728 после установки `[30349]`) — рендер.

## Найденное в оригинале
- **Ошибка в 0x15b20** (выбор цели атаки ИИ): обе петли по списку юнитов заканчиваются `or edx,edx; je <начало>` вместо `jne` — реально проверяется только первый юнит списка; если его `next == 0`, переход к записи 0 пула. Порт воспроизводит буквально (с защитой от зацикливания). Т.е. цель ИИ почти всегда — первая запись в списке юнитов владельца-цели.
- В 0x15b20 `shl ax,0xe0` — сдвиг на 0 бит (0xe0 & 0x1f), Y кладётся в задачу без выравнивания, X — выровнен по 32.
- 0x14642 (приказ 0x4x выбранному юниту) берёт цель из `edi`, который в 0x1419e равен `код>>4` (мусор из `mov edi,eax; shr edi,4`).
- В одиночной игре случайный спавн артефактов внутри 0x13f4c не выполняется (блок только при `[31b69]!=0`); очередь приказов служит только для UI-приказов текущего шага — ИИ пишет поля `+46..+4d` напрямую (0x19f43).

## Исправления в общих файлах (важно для всех тем)
- `oracle.py::start()`: счётчик шагов `[31ab4]` — dword (`inc dword`), раньше обнулялся как u16, и старшее слово оставалось мусором после загрузки → ГСЧ (`add eax,[31ab4]`) считал с другим значением, чем настоящая игра. Теперь `w32`. Все трассы/кейсы, снятые до этого, содержат старшее слово 0x0002 в `[31ab4]`.
- `js/engine.js`: `rand_raw` читает `[31ab4]` как u32; тик инкрементирует dword и `[31b66]` как u16.
- `fncheck.py`: `--poke ADDR=VAL[,…]` (суффиксы `:w`/`:d`) — установить память перед вызовом; `--ptr esi,edi` — регистры-указатели в данные (в эмуляторе +RELOC, в `case.json` — адреса оригинала).
- Инъекция приказов в эталон: `o.order()` (вызов 0x14895 до шага) НЕ работает — 0x13f4c сбрасывает указатель очереди в начале шага. Приказ игрока задаётся как ожидающий UI-приказ: `[31acc]=код, [31ad0]=цель/юнит, [31ad4]=X, [31ad8]=Y` плюс выделение юнитов (`+07 |= 0x80`, для кодов 0x4x/0x5x/0x7x — `[31adc]`=юнит). В `trace.py` это стоит переделать так же.

## Неясное
- Обработчики 0x1469a/0x146c5/0x146fa не покрыты кейсами (нужен 0x14873).
- В `TAB_1ac98` (снаряды 0x80+) записи после 41-й — мусор в таблице оригинала; порт бросает исключение на таких типах.
