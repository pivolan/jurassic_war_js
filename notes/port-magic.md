# Порт темы D: магия, предметы, решения юнита (js/port/magic.js)

Все функции проверены пофункционально (`cases/magic/*`, 101 кейс, все проходят) и интеграционно (трассы m0_t0, m0_t0_orders, m1_t1, m3_t5, m5_t0, m9_t3 — совпадение 100%).

## Портировано (адрес → назначение)
- **Решения перед диспетчером**: 0x163e4 (регенерация маны от тотемов раз в 4 шага: тип 5→предмет 0x11, 6→0x1d, 7→0x13, 8→0x14; развилка по состоянию), 0x16508 (отдых: выйти, когда HP и мана полные), 0x16531 (в бою: 0x166e0 «слаб ли» → 0x1674b самолечение; 0x17014 раненый союзник в бою → 0x16916; иначе 0x16a10), 0x16598 (охрана/задачи ИИ: 0x16612 подбор предметов, 0x1664a/0x1669f задачи из блоков 0x32bcc/0x32c1c), 0x166e0, 0x1674b, 0x16916, 0x16841 (ИИ-прогулка: телепорт 0xb2 при умении 0x1a, иначе случайный шаг ±192 px в одном из 8 направлений через 0x1e609), 0x16a10 (выбор атакующего заклинания по максимуму оценки), оценщики 0x16c1f/0x16cb9/0x16da7/0x16e32/0x16eef/0x16f01/0x16f08/0x16f0f/0x16f24/0x16f2c/0x16f36/0x16f43/0x16f4a/0x16f5e, 0x17014, 0x170f6 (+0x171d3 флаги свободных слотов) — поиск предмета на земле, который юнит может взять.
- **Умения/мана**: 0x14873 (бит умения + мана ≥ стоимости), 0x1c092 (списание маны, возвращает стоимость в AL), 0x1c1b2 (лечение с насыщением), 0x1f475 (открытие заклинаний по MAG через маску игрока 0x30e64[slot][type]).
- **Заклинания** 0x1b917 (все 16 + пустые), эффекты: 0x1bffc (снаряд-эффект на цель), 0x1c052 (в точку), 0x1bc8a/fireMissile (огненный снаряд), поиск врагов 0x1c0b2/0x1c0b8, 0x1c135/0x1c13b; аллокатор юнита 0x1aaac (для подчинения 0x84).
- **Состояния магии** (таблица 0x182c8): 0x197e5, 0x19872, 0x1990c, 0x1999e, 0x19a2b, 0x19a91, 0x19abd, 0x19adc, 0x19afb, 0x19b0a, 0x19b41/49/51, 0x19b59, 0x19b78, 0x19b8c, 0x19ba7; сеттеры приказов 0x1a379, 0x1a393, 0x19fbf, 0x19f63; проверка радиуса 0x1a2f2.
- **Предметы**: 0x1c5d6 (экипировка: бонусы с насыщением, HP/мана с потолком), 0x1c72b (автозелье при HP < ½), 0x175e8 (снять/продать), 0x1763c (купить), 0x17671 (ближайший свой арсенал).
- **Звук**: 0x1ffaa/0x1ffb6 → 0x2000d (запрос в таблицу 0x38870+id·8 с громкостью по расстоянию до камеры — портирован, потому что пишет память).

## Найденные неточности и правки чужого
- **move.js: таблица TAB_182C8** была обрезана до 8 записей (0x80–0x87); состояния 0x88–0xd2 (приказы-касты 0xa0.., анимация 0xc0..) не диспетчеризовались. Дополнена полной таблицей 0x182c8 (96 записей). Это и была причина расхождений m5_t0/m3_t5/m9_t3.
- 0x19872 (состояние 0x84): проверка цели ИНВЕРТИРОВАНА относительно остальных — подчинение работает только по цели в состоянии 0x60, иначе сброс приказа.
- 0x1763c: при покупке списывается **вся** еда юнита (`mov ax,dx` = FOOD), а не цена — так в оригинале.
- 0x16f5e (массовое лечение, оценка): проверка границ карты инвертирована (`jae`), обрабатываются только клетки вне карты, читается MO по строке 0 — воспроизведено буквально; практически оценка всегда 0.
- 0x170f6: при непищевом предмете счётчик колец ECX перезаписывается флагами предмета — воспроизведено.
- 0x19f63: Y цели берётся у esi (баг оригинала) — воспроизведено.
- Не портированы вызовы UI: 0x2673d (панель при росте умений) и 0x26671 (перерисовка инвентаря) — только рендер выбранного юнита; 0x2000d портирован полностью.
- Спавн артефактов — в теме E (0x13f4c), не трогал.

## Замечания к GAME-LOGIC.md
- Поле +0x46 «приказ» = заклинание+0x20 (0xa0..0xae, 0xb2 телепорт-прогулка ИИ); состояние = приказ → −0x20 после построения пути (0x19b0a) → каст (+0x40) → анимация → 0x3f.
- Стоимость заклинания читается через 0x30bbe[id&0x7f] → 0x30b61+off; 0x14873 сравнивает ману с 0x30b41+off (та же таблица со смещением −0x1f).
